# qexec v0.2.0 — Area Actions Preview

This preview adds a What to do page and connects discoveries to executable actions: browse shops and monster drops, accept area quests, and generate a farm for a selected item.

## New workflows

- **What to do:** discover the current area's shops, monsters and quest sources. Open quests in game or accept them directly, with exact quest IDs and acceptance checks.
- **Direct item actions:** Farm item, Buy item and Farm & merge resolve supported material chains and start generated scripts. Gold and merge materials may be consumed. AC items open their shop without an automatic purchase.
- **Quest Ledger:** clicking a quest starts Auto-do directly. Multiple reward choices, progress, errors and cancellation remain inline.
- **Return travel:** generated quests return to the recorded acceptance map/cell before turn-in. If acceptance was not observed, the Auto-do starting location is used.
- **Item previews:** lazy, cached wiki thumbnails and an enlarged gallery across gear, drops, shops, ingredients, farm plans, catalog entries and selectable rewards. Supports direct artwork markup and item disambiguation pages.
- **Become OP:** uses the installed CoreAdvanced enhancement library for the equipped class, then attempts to activate matching owned tonics/elixirs from inventory or bank. Consumable presets cover Void Highlord, Chaos Avenger, ArchPaladin, Legion Revenant, ArchMage, LightCaster and Scarlet Sorceress. Other classes receive the enhancement routine only. Missing consumables are reported, not farmed automatically.

## Reliability and speed

- Area scans cache wiki pages and shop indexes; deep SWF discovery is deferred until requested. Shop browsing snapshots ownership once and defers bank loading until acquisition planning.
- Map pickup discovery reads bytes from the map already loaded in Flash, avoiding the failing separate HTTP map download.
- Pickup collection can search playable cells with bounded retries and Stop checks.
- Mixed kill/pickup quests no longer assign every temporary objective to a monster. Investigate the Ruins includes verified offline routes for Plant Found and Underworld Hound Defeated.
- Handles plural location fields, including the Chest Thumping route; supports verified literal map pickup calls such as Reveal the Portal.
- Death-dealing Blows explains its PvP requirement instead of reporting an ordinary missing drop route. PvP completion remains manual.
- Late renderer callbacks and host messages no longer access destroyed windows during shutdown.
- Generated acquisition plans verify item quantities, shop recipes, prices, membership and stale selections before acting.

## Download and setup

Download **qexec-v0.2.0-macos-apple-silicon.zip** and check it against **SHA256SUMS.txt**. The archive contains qexec.app, setup instructions, attribution and the scoped Flash trust helper.

The Apple Silicon .NET host is bundled. The Intel Electron renderer requires **Rosetta**, an existing **Artix Game Launcher Flash plugin**, compatible external **Skua scripts/CoreBots**, and **Java/OpenJDK** for map inspection. The app is **ad-hoc signed, not notarized**. Account data, user settings, personal scripts and the proprietary Flash plugin are not included.

## Validation and known limits

Backend regressions, four Node test suites, Flash bridge compilation, app signature verification and generated C# compilation cover the release. Wiki fixtures exercise real artwork and mixed-objective layouts; the complete Investigate the Ruins script resolves both online-fixture and offline routes. These checks do not establish live completion of every quest or successful activation of every class setup.

This remains a preview. Unknown prerequisites, unavailable bank data, changing wiki pages, ambiguous pickups and complex story chains can block automation. Becoming OP does not unlock every Forge enhancement or automatically farm missing consumables. The legacy Electron/Flash runtime remains a compatibility dependency. The reported Chaos Beast Trophy lookup is still under investigation.

Thanks to the Skua, RBot and script community contributors. qexec is not an official Artix client; inherited notices and licensing remain in place.
